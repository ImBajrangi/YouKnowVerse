# AcademicPro India — Changelog

## [1.0.0] - 2026-11-19
### Initial Production Release
- **Full Marketing Platform**: High-conversion homepage with hero, 6 service cards, 4-step process, trust indicators, verified testimonials, and Mathura office details.
- **Service Details**: Dedicated deep-dive pages for all 6 core services and specialized statistical offerings.
- **Consultation Booking System**: Google Meet & Mathura in-person session scheduler with automated confirmation.
- **Lead Generation & Quotation Calculator**: Dynamic quote estimation wizard with instant lead logging and WhatsApp CTA.
- **Client Workspace**: Complete scholar portal featuring 11-stage project lifecycle tracker, private document vault, milestone sign-offs, and consultant messaging.
- **Director / Admin Console**: Full inbound lead pipeline, project progress controller, quotation & invoice manager, and dynamic FAQ CMS.
- **Strict Concentric UI Geometry**: $R_{\text{inner}} = R_{\text{outer}} - \text{padding}$ enforced across all components with zero generic hover animations.
- **26-Table Database Architecture**: Complete PostgreSQL schema with Row Level Security, role-based access control, and initial seed data.
